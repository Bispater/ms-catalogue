## 📞 **SOPORTE**

### **Scripts Disponibles**
```bash
# Probar sistema
python scripts/test_import.py

# Importar productos
python scripts/transform_client_excel.py excel.xlsx catalogo-slug

# Analizar Excel
python scripts/analyze_client_excel.py excel.xlsx

# Migrar datos
python scripts/migrate_to_catalogues.py
```

### **Comandos Útiles**
```bash
# Iniciar proyecto
docker compose up -d

# Ver logs
docker compose logs -f web

# Shell de Django
docker compose exec web python manage.py shell

# Crear superusuario
docker compose exec web python manage.py createsuperuser
```
